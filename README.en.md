# Sweeping View

English | [简体中文](README.md)

A Fabric client mod that visualises the hit range of Minecraft's sweeping attack.

While the player holds a sword and is aiming at an entity, the mod draws in the world:

- **Sweeping range** — the target's bounding box expanded by 1 block horizontally and
  0.25 blocks vertically;
- **Attack range** — a sphere of radius 3 blocks centred on the bottom face of the attacker's
  bounding box.

## Configuration

Reach the YACL screen through ModMenu:

| Option | Default |
| --- | --- |
| Box outline | on |
| Box outline colour | `#FF5050` |
| Box faces | on |
| Box face colour | `#FF5050` |
| Sphere | on |
| Sphere colour | `#FF5050` |
